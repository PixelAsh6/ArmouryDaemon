The published executable is built for the x86-64 v3 level: AVX2 and the rest of the third set of instructions. The build is the same on every machine, and it runs on Intel from 2013 (Haswell) and AMD from 2015 (Excavator).

## What else changed

- The pack script's sandbox built a new interpreter and registered its host functions on every run. It keeps one engine now: the 432.7 µs the build used to cost is paid once, and a run spends 4.7 µs on the engine.
- The killswitch enumerated the machine's audio sessions once per tracked app. It enumerates them once for the whole press now, and restores from its ledger on release without enumerating at all: about 45 ms off the event loop on each press.
- The daemon walked the process table every tick, even with nothing tracked. The walk is skipped when no applications are tracked: it cost about 19.5 ms a second, and it now happens only when there is something to find.
- The killswitch unmuted an audio session the user had muted themselves. Only the sessions it changed are restored now.
- The console band is centred on the screen again and is allowed to cover the dashboard, because the band is used to launch a game from a controller while the user is away from the computer.

The pack format, the catalogue and the shipped packs are unchanged.
