The lockout now holds a change in both directions. A tracked app that closes waits for the window, and a tracked app that starts inside a window waits too: the packs stay as they are until the window is over, the change lands exactly once, and it lands only if the app is still running by then. A restart inside the window cancels the held change, so the packs stay applied. A manual action - pausing, removing a tracked app, entering or leaving idle mode - still bypasses the window and happens at once.

The old rule deferred only some changes. A tracked app that closed between two windows reverted the packs at once, and the restart that followed was stuck behind the revert's own window: the machine sat in the quiet mode while the game was running, and the logs showed the revert before the apply.

## What else changed

- The release carries the executable and its hash sidecar, and nothing else. There is no zip and no scripts in it: the executable installs itself, and the scripted install lives in the deploy folder of the repository.

The pack format, the catalogue and the shipped packs are unchanged.
